# 资源过期回收

当资源到期或欠费，为避免资源进入停服状态对您的业务产生影响，请您及时续费或充值。

## 预付费-按时（使用时长 < 3 天）

| 时间节点 | 动作 |
|---------|------|
| 过期时间 t0 | 停服通知 |
| t0 + 1h | 回收告警 |
| t0 + 3h | 回收通知 |

## 预付费-按时（使用时长 ≥ 3 天）

| 时间节点 | 动作 |
|---------|------|
| 过期时间 t0 | 到期通知 |
| t0 + 20h | 回收告警、停服 & 回收通知 |
| t0 + 1 天 | 回收通知 |

## 预付费-按天

| 时间节点 | 动作 |
|---------|------|
| 过期时间 t0 | 到期通知 |
| t0 + 1h | 停服通知 |
| t0 + 3h | 回收告警、回收通知 |
| t0 + 20h | 回收通知 |

## 预付费-按月

| 时间节点 | 动作 |
|---------|------|
| 过期前 7 天 | 过期提醒 |
| 过期前 3 天 | 过期提醒 |
| 过期时间 t0 | 到期通知 |
| t0 + 2 天 | 停服告警 |
| t0 + 3 天 | 停服通知 |
| t0 + 9 天 | 回收告警 |
| t0 + 10 天 | 回收通知 |

## 预付费-按年

| 时间节点 | 动作 |
|---------|------|
| 过期前 7 天 | 过期提醒 |
| 过期前 3 天 | 过期提醒 |
| 过期时间 t0 | 到期通知 |
| t0 + 2 天 | 停服告警 |
| t0 + 3 天 | 停服通知 |
| t0 + 9 天 | 回收告警 |
| t0 + 10 天 | 回收通知 |
